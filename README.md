# office-toolkit · 允澈工坊

给 Windows 办公场景做的**零依赖小工具合集**。每个工具都是单个 exe，双击就能用，不联网、不上传、不留后台全家桶。

全部开源免费（MIT）。

---

## 工具清单

| 工具 | 干什么 | 体积 | 状态 |
|---|---|---|---|
| [喝水提醒](tools/water-reminder/) | 只在工作时段提醒你喝水，进时段先弹一杯、午休自动跳过，玻璃质感弹窗，缩在托盘里 | 8.0 MB | ✅ v0.9.0 |
| [批量重命名](tools/batch-renamer/) | 八条规则链批量改名，执行前预览、撞名标红，**改错了一键撤销** | 7.6 MB | ✅ 可用 |

后面还会加图片批量处理、Excel 批量合并之类——都是自己每周真在用的活儿。

---

## 这些工具的共同脾气

- **零第三方依赖**：只用 Python 标准库 + 系统自带的东西，不装运行库
- **单文件 exe**：解压即用，不用管理员权限，不写系统目录
- **不联网**：数据全在本机，代码里没有一行网络请求
- **内存占用小**：托盘常驻 20 MB 上下，空闲时 CPU 接近 0
- **能改**：源码都在这儿，配置是明文 JSON，文案随便改

## 目录结构

```
office-toolkit/
├─ README.md              这个首页
├─ LICENSE                MIT
├─ docs/
│  └─ REPO-PLAN.md        仓库规划、发布流程、注意事项
└─ tools/
   ├─ water-reminder/     喝水提醒
   │  ├─ README.md        工具说明
   │  ├─ CHANGELOG.md     改动记录（版本号来源是 src/core.py 的 VERSION）
   │  ├─ src/             源码（纯标准库）
   │  ├─ tests/           单测 + 真机自检
   │  ├─ assets/          图标
   │  └─ build.py         打包脚本
   └─ batch-renamer/      批量重命名
```

每个工具自成一个目录，互不依赖，单独下载也能跑。
