# 喝水提醒 💧

Windows 上按**工作时段**提醒你喝水的小工具。玻璃质感弹窗，缩在托盘里，8 MB 单文件 exe。

> 只在上班时间烦你，午休不打扰，下班就闭嘴。
> 数据是本地明文 JSON，不联网。

## 和别的喝水提醒有什么不一样

| | 常见的 Python 喝水 App | 这个 |
|---|---|---|
| 依赖 | PyQt / PySide，装一堆东西 | **零第三方依赖，纯标准库** |
| 体积 | 40–80 MB | **8 MB 单文件** |
| 常驻内存 | 60–100 MB | **约 20 MB** |
| 提醒逻辑 | 全天定时 | **只在工作时段，午休自动跳过** |
| 记录方式 | 打开窗口点按钮 | **弹窗上直接点「喝了 250 ml」** |
| 界面 | 系统原生灰白窗口 | **深色玻璃拟态自绘 + 系统圆角投影** |
| 数据 | SQLite / 云端 | **本地 JSON，想删就删** |

## 功能

- 工作时段内按间隔弹提醒（默认 9:00–18:00，每小时 250 ml）
- 一进工作时段就先提醒一次：早上打卡、午休结束、暂停到期，都不用等满一个间隔
- 时段填成 22:00–06:00 这种跨夜夜班也认（界面会标"跨夜"）
- 弹窗上直接显示今日进度，三个按钮：`喝了 250 ml` / `15 分钟后` / `今天不提醒`
- 弹窗下面有倒计时，写清楚"几秒后收起、没人点会怎样"
- 30 秒没理它会自己收起；没人响应算"没看见"，15 分钟后再提醒一次，
  连续两次还是没人理就回归正常间隔，不会追着吵
- 弹提醒时带一声系统轻提示音，可在设置里关掉
- 午休免打扰（默认 12:00–13:00，可关）
- 周末可选不提醒
- 达成目标弹一次庆祝，当天不再打扰；手滑撤销回目标以下，庆祝还能再来一次
- 托盘常驻，右键菜单：打开设置 / 立刻提醒一次 / 记一杯 / 撤销上一次记录 /
  暂停 1 小时（再点取消）/ 今天不再提醒（再点恢复）/ 开机自启 / 关于 · 允澈工坊 / 退出
- 设置窗底部有署名行「制作 by 允澈工坊 · 喝水提醒 v0.9.1」，点它（或托盘那个「关于」）
  弹一个关于窗：版本、仓库地址、许可协议、是否联网，地址能一键复制也能直接打开
- 鼠标停在托盘图标上就能看到"为什么不弹"：暂停中、今天已静音、不在时段、下一杯几点
- 手滑点「退出」不会真退：要在 8 秒内点第二次才算确认
- 开机自启（可选，写 HKCU 注册表，不需要管理员）；以注册表实际状态为准，写失败会回退界面
- 深色 / 浅色 / 跟随系统三档外观，卡片配色是两套配方分别调的
- 显示单位可选 ml / oz（存储永远是毫升，只影响界面怎么写）
- 提醒文案随便改，一行一条，随机且不连着重复
- 配置填坏了会被收进合理范围（间隔 5–480 分钟、单次 50–2000 ml 等），
  并在界面上明说"哪一项从多少改成了多少"；JSON 写坏时原件另存备份，不丢设置
- 记录一天一个 JSON，超过 400 天自动挪进 `data\archive\`（只挪不删）

## 怎么用

1. 从 [Releases](https://github.com/yunche-workshop/office-toolkit/releases) 下载 `WaterReminder.exe`
2. 双击运行 → 右下角出现水滴托盘图标，同时弹出设置界面
3. 填四个数：上班时间、下班时间、每隔多久、每次喝多少
4. 点「保存」

想立刻看效果，点界面上的「测试提醒」（这条不会追着你提醒）。
关掉设置窗口不会退出程序，它缩在托盘里；要彻底退出，托盘右键 → 退出，
它会先问你一次，8 秒内再点一次才真的退。

记错了想撤回：托盘右键 → 「撤销上一次记录」，撤掉的就是最近那一条。

不小心双击了第二次 exe？不会开出两个程序，它会把已经在跑的那个界面唤到前台。
设置窗底部的「打开数据目录」直接跳到 `config.json` 和 `data\` 实际所在的位置。

> 第一次运行会在 exe 同目录生成 `config.json` 和 `data\`，整个工具搬家时把这两个
> 一起带走就行。exe 放在 `Program Files`、桌面以外的只读位置时写不进去，
> 程序会自动改用 `%APPDATA%\WaterReminder\`，并在 `run.log` 里写一行说明——
> 这种情况下要改的就是 APPDATA 里那份，不是 exe 旁边那份。

## 配置说明

界面上改完点保存即可，也可以直接编辑 `config.json`：

| 字段 | 说明 | 默认 |
|---|---|---|
| `workStart` / `workEnd` | 工作时段，超出不提醒；填成 22:00–06:00 这种跨夜也认 | `09:00` / `18:00` |
| `intervalMinutes` | 提醒间隔（分钟），有效范围 5–480 | `60` |
| `amountPerReminder` | 每次提醒的水量（**永远是毫升**），50–2000 | `250` |
| `dailyGoal` | 每日目标（毫升），200–10000 | `2000` |
| `snoozeMinutes` | 点「稍后」以及弹窗没人响应时延后多久（分钟），5–120 | `15` |
| `lunchBreak` | 午休免打扰，`enabled` 可关 | `12:00`–`13:00` |
| `workdaysOnly` | `true` = 只在周一到周五提醒（旧键名 `weekendsOnly` 仍兼容读取） | `false` |
| `autoStart` | 开机自启。实际以注册表为准，两边不一致时以注册表回写界面 | `false` |
| `sound` | 弹提醒时放一声系统提示音 | `true` |
| `theme` | `auto` 跟随系统的深色/浅色，也可钉死 `dark` / `light` | `auto` |
| `unit` | 界面显示单位：`ml` / `oz`。只影响显示，存储与填写都是毫升 | `ml` |
| `messages` | 提醒文案，一行一条，随机且不连着重复 | 12 条 |
| `goalReachedMessage` | 达成目标时的文案 | — |

超出范围或写坏的值不会让程序崩：会被收进合法区间，界面上标出"哪一项从多少改成了多少"，
`run.log` 里也留一行。时间字段写 `"25:00"` 这种，回落到默认值并同样说明。

默认组合：9:00–18:00，每小时 250 ml，8 次正好 2000 ml。

> 界面用的是系统字体，显示不了彩色 emoji，会自动过滤掉。
> 配置文件里可以保留 emoji，不影响记录。

## 技术实现

想抄的可以直接看 `src/`，一共六个文件、四千一百行：

| 文件 | 干什么 |
|---|---|
| `src/core.py` | 配置、存储、时间判断、单位换算、日志、版本号 |
| `src/brand.py` | 品牌名 / 仓库地址 / 许可 / 关于窗那几行的唯一文案来源 |
| `src/win32ext.py` | 窗口圆角/投影、拖拽、托盘、自启动、单实例、前台唤起、提示音（全是 ctypes） |
| `src/ui.py` | Canvas 自绘控件：按钮、开关、分段选择、进度条、7 天柱状图、可点击文字、玻璃窗口、关于窗 |
| `src/icon.py` | 图标兜底：资源缺失时用纯 Python 现画一个水滴 ICO |
| `src/main.py` | 入口、托盘消息循环、调度（`check`）、异常兜底 |
| `tests/` | 单测 + 真机自检，见下 |

几个值得说的点：

- **玻璃质感**：不使用 `-transparentcolor` + 亚克力的"透明分层窗口"组合——那套方案在部分机器上拖动窗口会直接触发 DWM 崩溃（闪退）。改用稳定的玻璃拟态（glassmorphism）实色方案：实底窗色 + 等效混色卡片 + 1px 亮边 + 顶部高光带 + 系统圆角和投影，观感接近，但绝不黑屏、不点击穿透、拖动不闪退。深浅两套配色是分开调的两张配方表，不是反色
- **托盘**：手写 `Shell_NotifyIcon` + 独立消息线程，不占 Tk 主线程，也不用 pystray
- **调度**：只有一条 `after(500ms)` 心跳，到点才读盘判断，空闲 CPU 接近 0；
  "刚进时段"和"时段内重置计时"分开处理，前者立刻弹第一杯，后者不吵人
- **图标**：多尺寸 .ico 打进包里（开发期用 `make_icon.py` 从一张母图生成，抠底/缩放/ICO 封装全是标准库），16/24 这两帧是按母图轮廓重画的——1024 的高光缩到 16px 会糊成一团，重画才看得出水滴的尖；资源万一缺失，`icon.py` 会运行时现画一个兜底。全程不依赖 Pillow
- **异常**：Tk 回调、主线程、子线程的未捕获异常都会落进 `run.log`。windowed 打包后没有控制台，不接住的话表现就是"程序还在，但到点不提醒了"
- **exe 元数据**：版本号只有 `core.VERSION` 一个来源，打包时生成 `--version-file`，
  资源管理器里的文件说明/公司/版权/版本号都是实的，反馈问题时能报出自己用的是哪一版
- **署名和关于**：品牌名、仓库地址、协议、关于窗的六行文案全在 `brand.py`，
  版本号在 `core.VERSION`，简介在 `core.SUMMARY`——界面上那行小字、关于窗、
  `--version`、exe 文件属性读的都是这几处，改一处就全跟着改，不会打架。
  仓库地址显示时去掉 `https://`（带着协议头在 420px 宽的窗里会撑成两行顶到卡片边），
  复制和打开用的仍是完整地址

自己打包：

```bash
pip install pyinstaller
python build.py        # 产物在 dist/WaterReminder.exe
```

跑测试（改代码前后都过一遍，零依赖，Python 3.8 起）：

```bash
python -m unittest discover -s tests   # 67 项纯逻辑断言：配置纠正、时段、调度、存储、单位、日志
python tests/smoke.py                  # 48 项真机只读接口：Win32 边界计算、图标、单实例
python tests/ui_check.py               # 35 项界面自检：会闪几下窗口，用临时目录，不碰你的真实数据
```

三套合计 150 项。界面自检里那 13 项是查署名行和关于窗的（文案、位置、去重、剪贴板内容、
文字有没有被窗口上下沿裁掉），改界面时别把它们删了。

## 常见问题

**托盘图标没出现？**
检查系统托盘的「隐藏图标」区域，可能被折叠了。程序本体仍然在跑，看进程里有 `WaterReminder.exe`。

**半天没弹过提醒？**
按这三条查：① 进程还在不在——右下角托盘有没有水滴图标，任务管理器里有没有 `WaterReminder.exe`，不在就打开「开机自启」；
② 当前时间是不是被规则挡掉了——不在工作时段、正卡午休免打扰、勾选了只在周一至周五、或者点过「今天不提醒」；
③ 弹了但你没看见——弹窗 30 秒无操作会自动收起。exe 同目录的 `run.log` 会记每一条
（`进入工作时段，先提醒一次` / `弹出提醒：…` / `提醒没人响应（自动收起），追一杯`），翻一眼就知道是没弹还是没看见。

**玻璃效果没出来，是实色的？**
这是故意的。实色 + 系统圆角投影就是最终方案，不是降级：早期用透明分层窗口做亚克力，
部分机器上拖动窗口会直接闪退。现在这套在 Win10 1709 以下、远程桌面、各种显卡驱动上表现一致。

**开机自启没生效？**
设置里那个开关读的是注册表实际状态（`HKCU\...\Run`，只对当前用户生效，不需要管理员）。
如果写完发现开关自己弹回去了，说明这次没写进去——被组策略拦了，或者安全软件在拦启动项。

**换图标？**
准备一张纯色品红底的 PNG 母图，跑 `python make_icon.py 母图.png assets/app.ico`，
再 `python build.py` 重新打包。没有 `assets/app.ico` 时程序会退回运行时自算的水滴
（生成在 `data/icon.ico`），功能不受影响。

**上夜班 / 时段填反了怎么办？**
时段支持跨夜：`workStart` 填 `22:00`、`workEnd` 填 `06:00` 就是晚上 10 点到早上 6 点，
界面上会标"（跨夜）"。午休同理。

**我改的配置数字怎么自己变了？**
超出合理范围的值会被收进范围（比如间隔填 9999 → 480），输入框里会直接显示生效值，
窗口顶部也会写明"提醒间隔 9999→480"。这样下次保存不会又拿那个坏值再纠一遍。

**`config.json` 被我改坏了（少个逗号）会怎样？**
不会丢设置：原件另存成 `config.json.bad-*`，这次先用默认值，界面上会告诉你备份在哪。
把备份文件改名回去就行。

**记录会不会越攒越多？**
一天一个 JSON 文件。超过 400 天的自动挪进 `data\archive\`，只挪不删，历史永远在。
界面只显示最近 7 天。

**数据存哪、会不会上传？**
优先在 exe 同目录的 `data\`（便携）；那个目录不可写时自动改用
`%APPDATA%\WaterReminder\`，`run.log` 里会写一行说明用的是哪个。
代码里没有任何网络请求。
