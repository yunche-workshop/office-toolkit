# 喝水提醒 💧

Windows 上按**工作时段**提醒你喝水的小工具。玻璃质感弹窗，缩在托盘里，8 MB 单文件 exe。

> 只在上班时间烦你，午休不打扰，下班就闭嘴。
> 数据是本地明文 JSON，不联网。

| 数据 | SQLite / 云端 | **本地 JSON，想删就删** |

## 功能

- 工作时段内按间隔弹提醒（默认 9:00–18:00，每小时 250 ml）
- 一进工作时段就先提醒一次：早上打卡、午休结束、暂停到期，都不用等满一个间隔
- 弹窗上直接显示今日进度，三个按钮：`喝了 250 ml` / `15 分钟后` / `今天不提醒`
- 午休免打扰（默认 12:00–13:00，可关）
- 周末可选不提醒
- 达成目标弹一次庆祝，当天不再打扰
- 托盘常驻，右键菜单：打开设置 / 立刻提醒 / 记一杯 / 暂停 1 小时 / 开机自启 / 退出
- 开机自启（可选，写 HKCU 注册表，不需要管理员）
- 提醒文案随便改，一行一条，随机显示
- 30 秒没理它会自己收起；没人响应算"没看见"，15 分钟后再提醒一次，
  连续两次还是没人理就回归正常间隔，不会追着吵

## 怎么用

1. 从 [Releases](https://github.com/你的用户名/office-toolkit/releases) 下载 `WaterReminder.exe`
2. 双击运行 → 右下角出现水滴托盘图标，同时弹出设置界面
3. 填四个数：上班时间、下班时间、每隔多久、每次喝多少
4. 点「保存」

想立刻看效果，点界面上的「测试提醒」。
关掉设置窗口不会退出程序，它缩在托盘里；要彻底退出，托盘右键 → 退出。

> 第一次运行会在 exe 同目录生成 `config.json` 和 `data\`。
> 整个工具搬家时，把这两个一起带走就行。

## 配置说明

界面上改完点保存即可，也可以直接编辑 `config.json`：

| 字段 | 说明 | 默认 |
|---|---|---|
| `workStart` / `workEnd` | 工作时段，超出不提醒 | `09:00` / `18:00` |
| `intervalMinutes` | 提醒间隔（分钟） | `60` |
| `amountPerReminder` | 每次提醒的水量（ml） | `250` |
| `dailyGoal` | 每日目标（ml） | `2000` |
| `snoozeMinutes` | 点「稍后」以及弹窗没人响应时延后多久（分钟） | `15` |
| `lunchBreak` | 午休免打扰，`enabled` 可关 | `12:00`–`13:00` |
| `workdaysOnly` | `true` = 只在周一到周五提醒（旧键名 `weekendsOnly` 仍兼容读取） | `false` |
| `autoStart` | 开机自启 | `false` |
| `messages` | 提醒文案，一行一条随机显示 | 12 条 |
| `goalReachedMessage` | 达成目标时的文案 | — |

默认组合：9:00–18:00，每小时 250 ml，8 次正好 2000 ml。

> 界面用的是系统字体，显示不了彩色 emoji，会自动过滤掉。
> 配置文件里可以保留 emoji，不影响记录。

## 技术实现

想抄的可以直接看 `src/`，一共四个文件：

| 文件 | 干什么 |
|---|---|
| `src/core.py` | 配置、存储、时间判断 |
| `src/win32ext.py` | 窗口圆角/投影、拖拽、托盘、自启动、单实例（全是 ctypes） |
| `src/ui.py` | Canvas 自绘控件：按钮、开关、进度条、玻璃窗口 |
| `src/icon.py` | 图标兜底：资源缺失时用纯 Python 现画一个水滴 ICO |

几个值得说的点：

- **玻璃质感**：不使用 `-transparentcolor` + 亚克力的"透明分层窗口"组合——那套方案在部分机器上拖动窗口会直接触发 DWM 崩溃（闪退）。改用稳定的玻璃拟态（glassmorphism）实色方案：深色实底 + 等效混色卡片 + 1px 亮边 + 顶部高光带 + 系统圆角和投影，观感接近，但绝不黑屏、不点击穿透、拖动不闪退
- **托盘**：手写 `Shell_NotifyIcon` + 独立消息线程，不占 Tk 主线程，也不用 pystray
- **图标**：多尺寸 .ico 打进包里（开发期用 `make_icon.py` 从一张母图生成，抠底/缩放/ICO 封装全是标准库），托盘按 DPI 取对应那一帧，不会被系统二次缩放糊掉；资源万一缺失，`icon.py` 会运行时现画一个兜底。全程不依赖 Pillow
- **省电**：空闲时只有一个 `after()` 主循环（只在到点时才读盘），CPU 接近 0

自己打包：

```bash
pip install pyinstaller
python build.py        # 产物在 dist/WaterReminder.exe
```

## 常见问题

**托盘图标没出现？**
检查系统托盘的「隐藏图标」区域，可能被折叠了。程序本体仍然在跑，看进程里有 `WaterReminder.exe`。

**半天没弹过提醒？**
按这三条查：① 进程还在不在——右下角托盘有没有水滴图标，任务管理器里有没有 `WaterReminder.exe`，不在就打开「开机自启」；
② 当前时间是不是被规则挡掉了——不在工作时段、正卡午休免打扰、勾选了只在周一至周五、或者点过「今天不提醒」；
③ 弹了但你没看见——弹窗 30 秒无操作会自动收起。exe 同目录的 `run.log` 会记每一条
（`进入工作时段，先提醒一次` / `弹出提醒：…` / `提醒没人响应（自动收起），追一杯`），翻一眼就知道是没弹还是没看见。

**玻璃效果没出来，是实色的？**
说明系统不支持亚克力（Win10 1709 以下，或者开了远程桌面/某些显卡驱动）。程序会自动回退到深色实底，功能不受影响。

**开机自启没生效？**
设置里打开开关后确认一次保存。它写的是 `HKCU\...\Run`，只对当前用户生效，不需要管理员。

**换图标？**
准备一张纯色品红底的 PNG 母图，跑 `python make_icon.py 母图.png assets/app.ico`，再 `python build.py` 重新打包。没有 `assets/app.ico` 时程序会退回运行时自算的水滴（生成在 `data/icon.ico`），功能不受影响。

**数据存哪、会不会上传？**
全部在 exe 同目录的 `data\` 里，一天一个 JSON。代码里没有任何网络请求。
