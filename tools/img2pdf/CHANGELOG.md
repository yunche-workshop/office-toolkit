# 更新日志

## 0.1.0（2026-10-09）· 第一个版本

第三个工具。定位和另外两个一样：**内网办公电脑上能用的绿色单文件 exe，不联网、
不安装、零第三方依赖。**

### 内核（`src/core.py`，纯标准库手写）

- **PDF 出口整个自己写**：对象号分配、xref 表、`/Catalog /Pages /Page /XObject`、
  `cm` 放置矩阵、`BI...ID...EI` 内联图像、UTF-16BE 元数据字符串。
  不用 img2pdf 库、不用 Pillow —— 那两个都是第三方依赖，和"单文件绿色版 + MIT"
  这条品牌承诺冲突
- **JPEG 原样封装（`/DCTDecode`）**：只读头部拿宽高/色彩空间/密度/EXIF 方向，
  码流一个字节不动地塞进 PDF。所以"转 PDF 不掉画质"不是话术，是结构上的必然
- **PNG 自己解码**：块遍历、5 种行滤波（None/Sub/Up/Average/Paeth）、
  位深 1/2/4/8/16、色彩类型 0/2/3/4/6、`PLTE` + `tRNS`、`pHYs` 读密度
- **alpha 拆成 `/SMask` 软掩膜**：透明 PNG 进 PDF 还是透明的
- **CMYK JPEG 加 `/Decode` 反相**：PDF 规范要求 CMYK 按 Adobe 约定反向解释，
  不写这个颜色整个是反的
- **EXIF Orientation → 放置矩阵**：手机竖拍的照片不会躺倒
- 排版：按图片大小 / A4 / A5 / Letter，方向自动或强制，页边距、DPI 可覆盖，
  纸张模式下等比缩放居中
- 输出走 `tmp` + `os.replace` 原子写；目标被占用时自动换名，不覆盖坏用户已有文件
- 一批里有坏图：**跳过并在结果里点名**，不中断整批

### 界面（`src/ui.py`）

- DPI 感知 + 200% 缩放适配，深色主题，和另外两个工具同一套配方
- 页列表可上移/下移调页序、删除、清空；每行显示尺寸、密度、是否带透明
- 参数区：纸张下拉（选"按图片大小"时方向自动灰掉）、页边距、DPI、文档标题、
  输出路径（默认落在首图旁边，叫 `<首图名>等N张.pdf`）
- 转换在**后台线程**跑，主线程用 `after()` 收队列 → 几百张图也不会"未响应"
- 底部常驻署名「制作 by 允澈工坊 · 图片转 PDF v0.1.0」，点它弹关于窗
  （六行内容来自 `brand.py`，和另外两个工具字节一致）

### 命令行

- 带参数就不弹窗直接干活：`Img2Pdf.exe 目录 -o 输出.pdf --paper A4 --margin 20`
- `--help` / `--version`；退出码 0 成功 / 1 读不了 / 2 参数错，批处理里能判断
- 自己拆参数不用 `argparse`：3.8 的 argparse 中文提示跟着系统代码页走，容易乱码

### 这一轮踩到并修掉的坑（别回退）

- **`page_points` 从来没被真正验到过**：验收脚本所有用例都强制 `dpi=72`，
  于是"像素数 == 磅数"，把 DPI 换算整段删掉照样全绿。补了「1b) 物理尺寸」一节
  （300 DPI 的图 → 28.8×14.4 磅、强制 150 DPI → 页面翻倍）
- **Pillow 会悄悄不配合**：`save(bits=2)` 对 L 模式**根本不写低位深**，
  IHDR 仍是 8 bit，于是"低位深透传"那几条断言在 8 bit 样本上空跑。
  改成 1 bit 用 Pillow 的 `"1"` 模式、2/4 bit 用测试自己写的编码器，
  并且每个夹具都回头查 IHDR（`assert_ihdr`）
- **`mean or -1` 这种写法会骗人**：像素完全一致时 mean 正好是 `0.0`，falsy，
  被显示成 `-1`，看着像出错其实是满分通过（同一类坑在"用文件大小当空白判据"上栽过）
- **`--windowed` 的 exe 里 `sys.stderr` 可能是 None**：`print()` 只是不输出，
  `sys.stderr.write` 直接 `AttributeError` —— 在"报错"这条路上崩掉最难查。
  统一走 `_say()`，没控制台时安静丢掉
- **工具中文名在 `ui.py` 里写死四遍**、页边距默认值在四个地方各写一遍：
  收进 `core.TOOL_CN` / `core.DEFAULT_MARGIN`
- 编辑时差点留下**两个同名 `print_version()`**（后一个静默覆盖前一个）：
  用 AST 把 `src/*.py` 的顶层和类内重名扫了一遍，确认零重名
- 界面侧：纸张下拉只绑了选中事件 → 从配置恢复/脚本改值时方向控件灰不掉，
  改成 `trace_add("write")`；转换成功后再调 `_refresh()` 会把"好了：N 页 · 多大"
  重算成参数摘要，用户看不到产物信息，去掉那次刷新
- 列表上方那行提示写死成"还没有添加图片"，加了 6 张图它还杵在那儿：
  **单测和冒烟都查不出来**（它们查的是控件存不存在、值对不对），
  是端到端截图脚本跑完、回头看图才发现的。改成按 `self.paths` 显示
  "共 N 张 · …"，并在 `smoke_ui.py` 里补了 5 条针对这行文案的断言
